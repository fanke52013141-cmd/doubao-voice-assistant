语音输入助手 macOS 个人测试版安装说明
=====================================

一、选择安装包

1. 点击屏幕左上角苹果图标，选择“关于本机”。
2. 如果“芯片”显示 Apple M1、M2、M3、M4 或后续 Apple 芯片，使用文件名带 AppleSilicon 的 DMG。
3. 如果“处理器”显示 Intel，使用文件名带 Intel 的 DMG。
4. 本测试版要求 macOS 11 Big Sur 或更高版本。

二、安装

1. 双击 DMG 文件。
2. 在打开的窗口中，把“语音输入助手”拖到右侧“Applications/应用程序”文件夹。
3. 等待复制完成，推出“语音输入助手”磁盘映像。
4. 打开 Finder → 应用程序。
5. 第一次不要直接双击：按住 Control 键点击“语音输入助手”，选择“打开”，再次点击“打开”。

三、如果系统阻止打开

本版本是个人测试版，只做了临时签名，没有使用 Apple Developer 证书进行公证。

1. 先尝试打开一次，让系统产生拦截记录。
2. 打开“系统设置 → 隐私与安全性”。
3. 滚动到“安全性”，找到关于“语音输入助手”的提示。
4. 点击“仍要打开”，输入 Mac 登录密码，再点击“打开”。
5. 只有在确认安装包来自本项目且校验值正确时，才允许这个测试版。

如果仍提示“应用已损坏”，可在终端执行下面这一条命令，仅清除本应用的下载隔离标记：

xattr -dr com.apple.quarantine "/Applications/语音输入助手.app"

然后回到“应用程序”文件夹重新打开。不要对整个“应用程序”目录执行该命令。

四、首次权限设置

1. 本地网络：出现网络访问提示时点击“允许”。手机和 Mac 必须连接同一个 Wi-Fi。
2. 辅助功能：要把手机文字、图片或视频自动粘贴到微信等软件，需要进入：
   系统设置 → 隐私与安全性 → 辅助功能
   打开“语音输入助手”的权限。
3. 如果权限列表里没有本应用，点击“+”，从“应用程序”中添加“语音输入助手”。
4. 修改权限后完全退出并重新打开应用。
5. 如果 macOS 防火墙询问是否允许接收传入连接，请选择“允许”。

五、连接手机

1. 打开 Mac 端语音输入助手，确认顶部状态为“已连接”。
2. 点击地址右侧复制按钮。
3. 把地址发送到手机并用手机浏览器打开。
4. 手机和 Mac 必须处于同一个局域网，访客 Wi-Fi 或开启“设备隔离”的路由器可能无法互访。
5. 地址包含本机配对凭证，不要转发给不信任的人。

六、基本操作

1. 手机发到 Mac：在手机网页输入文字，可选择传递或发送；图片、视频也可以发送到 Mac。
2. 自动粘贴：先在微信或其他目标软件中点击输入框，再从手机执行传递/发送。
3. Mac 发到手机：在 Mac 上方输入框填写文字，可点击“附件”选择图片、视频或普通文件，再点击“发送”。
4. 手机查看：打开“最近记录”查看文字和附件；图片可长按保存，普通文件点击“下载”。
5. 重启：重启按钮必须双击，单击只会显示提示。
6. 登录自启：设置页面中可开启“登录时自动启动”；请先确保应用已安装在“应用程序”文件夹。

七、常见问题

1. 手机打不开地址：确认同一 Wi-Fi，关闭手机蜂窝网络临时重试，并允许 Mac 防火墙传入连接。
2. 能收到但不能自动粘贴：检查“辅助功能”权限，退出应用后重新打开。
3. 粘贴后没有发送：先点中目标软件输入框，确认光标可见，再执行手机端发送。
4. 地址变化：更换 Wi-Fi 后，重新从 Mac 端复制新地址。
5. AI 按钮为空：在 Mac 端设置中填写 API 地址、密钥和模型，并启用对应规则。
6. 程序提示已运行但找不到窗口：在 Dock 中点击应用图标；仍无窗口时，在“活动监视器”结束语音输入助手后重开。

八、卸载

1. 退出语音输入助手。
2. 在“应用程序”中把“语音输入助手”移到废纸篓。
3. 如需删除配置和记录，在 Finder 菜单选择“前往 → 前往文件夹”，输入：
   ~/Library/Application Support/VoiceInputAssistant
4. 删除该文件夹会永久删除手机配对凭证、本地记录、AI 配置和已接收附件。
5. 如果开启过登录自启，再删除：
   ~/Library/LaunchAgents/com.fanke.voiceinputassistant.plist

九、安全提醒

本应用只应在可信局域网内使用。安装包未经 Apple 公证，仅适合本人测试，不建议公开分发。
