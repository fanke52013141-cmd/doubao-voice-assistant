# 语音输入助手 - 使用指南

## 一、在另一台 Windows 电脑安装

1. 把“语音输入助手-2.0.0-安装包.exe”复制到另一台电脑。
2. 双击安装包，按提示完成安装；安装程序会创建桌面快捷方式，并自动放行局域网访问所需的 TCP 56789 端口。
3. 双击桌面的“语音输入助手”。不需要另行安装 Python 或依赖库。
4. 确保电脑和手机连接同一个 Wi-Fi，然后用手机浏览器打开电脑窗口顶部显示的地址。

如果 Windows SmartScreen 提示“未知发布者”，请先确认安装包来源和 SHA256 校验值，再选择“更多信息”继续运行。本项目的安装包未购买商业代码签名证书。

## 二、日常使用

- 手机发送到电脑：在手机网页输入文字或选择图片，点击发送。
- 电脑发送到手机：在电脑输入框填写文字，可用“附件”选择图片、视频、Excel、Word、PDF 等文件，然后点击“发送”。
- 手机记录：文字可查看、填入输入框或复制；图片可长按保存；视频和其他文件可下载或调用手机系统分享。
- 重启：单击“重启”只显示操作提示，必须双击按钮才会真正重启，避免误触。
- 记录：电脑端和手机端均可在“记录”中查看最近传输内容。

## 三、连接要求

- 手机和电脑必须处于同一局域网。
- 更换 Wi-Fi 后，电脑的局域网地址可能变化，请以电脑窗口顶部当前显示的地址为准。
- 请不要关闭 Windows 防火墙。安装程序会添加仅允许当前程序通过 TCP 56789 的专用/域网络规则。
- 如果手机仍无法打开地址，请确认当前 Wi-Fi 在 Windows 中设为“专用网络”，并重新安装或以管理员身份运行程序一次。

## 四、从源码运行（开发者）

1. 安装 Python 3.10 或更高版本。
2. 在项目目录执行：`pip install -r requirements.txt`
3. 运行：`python launcher.py`

重新生成安装包时，需要安装 Inno Setup 6，然后运行：

`powershell -ExecutionPolicy Bypass -File .\build_installer.ps1`

构建脚本会自动创建纯英文路径的隔离构建环境，以兼容项目所在目录含中文字符的情况。
